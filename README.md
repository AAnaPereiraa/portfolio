# Ana Pereira — Portfolio

Personal portfolio site (Vite + React + TypeScript).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Production: [ana-pereira.vercel.app](https://ana-pereira.vercel.app)

```bash
npx vercel deploy --prod
```

Or connect the GitHub repo in the Vercel dashboard (Vite preset).
