# Ana Pereira — Portfolio

Personal portfolio site (Vite + React + TypeScript).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy free on Vercel

1. Push this repo to GitHub.
2. Go to [vercel.com](https://vercel.com) → sign up with GitHub (Hobby plan is free).
3. **Add New Project** → import `anapereira-portfolio`.
4. Framework preset: **Vite** (auto-detected). Deploy.
5. Optional: add a custom domain later.

Netlify also has a free tier; Vercel is the simplest default for Vite.
